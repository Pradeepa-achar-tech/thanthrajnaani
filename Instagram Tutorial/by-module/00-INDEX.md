# LocalInsta — Full Course Reels Series (Index)

The `../reel-scripts-01-10.md` file is the **trailer arc** — 10 reels giving a fast,
condensed tour of the whole build, meant to hook an audience and drive them to follow.

**This folder is the deep-dive arc** — one file per course module, 10 reels each,
**110 reels total**, genuinely covering everything taught in the 90-hour LocalInsta
course. Same format, same Kanglish/Karnataka energy, same 30-second pacing — just going
deep into each module instead of skimming the surface.

Post the trailer arc first to build an audience, then release these as **"Season 2"** —
one module's worth (10 reels) per week keeps a steady weekly drop for ~11 weeks.

## Format (same as the trailer arc, quick recap)

Every reel: **Hook (0-3s) → Setup (3-7s) → Payoff (7-24s) → Punchline (24-27s) → CTA
(27-30s)**. Kanglish dialogue, on-screen text callouts, a caption + hashtags ready to
paste. See `../reel-scripts-01-10.md` for the full style guide, catch-phrases, and free
production kit — it all applies here too, unchanged.

## Suggested posting order

Trailer arc (10 reels) → M0 → M1 → M2 → M3 → M4 → M5 → M6 → M7 → M8 → M9 → M10. This
mirrors the exact order a learner would actually build the app, so comments like "how do
I do the login part" land right when that module's reels are live.
